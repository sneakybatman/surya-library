Replacing the old VB6 + Oracle desktop app with a mobile-friendly family web app.
Work done on 2026-08-08.

## Deploying the app (one-time, ~15 minutes)

```sh
cd revamp/app
npm install                         # installs pinned wrangler only
npx wrangler login                  # opens browser
npx wrangler d1 create library-db   # copy database_id into wrangler.toml
npm run db:schema && npm run db:seed
npx wrangler secret put PIN         # the family PIN
npx wrangler secret put AUTH_SECRET # any long random string
npm run deploy                      # → https://library-surya.<acct>.workers.dev
```

Local development: `npm run db:schema:local && npm run db:seed:local && npm run dev`.

## Extraction findings

- **1,889 books** recovered from the newer dump (`DataBackup130722.dmp`, internal
  timestamp 31 Oct 2022). All accession numbers unique; 1,826 distinct
  (title, author) pairs; 53 titles have multiple copies (as duplicate rows).
- The older `DataBackup.dmp` is **truncated mid-file** (incomplete copy;
  1,886 complete rows recovered) and is a strict subset — the newer dump is canonical.
- Collection is **mixed Hindi + English**: Hindi literature (Premchand, Gita Press,
  Rajkamal) alongside English fiction (Clive Cussler ×47, Enid Blyton ×46, Penguin ×136).
- Columns that actually contain data: `ACCC_NO`, `TITLE` (99.9%), `AUTHOR_1` (99.8%),
  `AUTHOR_2` (composite "TITLE-AUTHOR" string), `PUBLISHER_NAME` (99.2%),
  `YEAR` (90.2%), `PG_COUNT` (98.5%). Everything else in the 67-column table is
  empty (a single test row aside).
- **⚠️ `ALMIRAH_NO` and `SHELF_NO` are empty in BOTH backups.** The old system never
  had location data. The new app's #1 feature (find where a book is) therefore needs
  a one-time family cataloguing pass: go almirah by almirah, search each book in the
  app, tap its location. The app should ship a fast "cataloguing mode" for this
  (search → tap almirah/shelf stepper → next book, sticky last-used values).
  Until then, location shows "जगह दर्ज नहीं है" per the UX spec.

## Design summary (see docs for detail)

- **Architecture** (`01`): no-build-step static PWA + one Cloudflare Worker + D1.
  $0/month, no cold starts, CSV-in-git backups, shared family PIN auth,
  optional ISBN scan via BarcodeDetector/zxing-wasm.
- **Schema** (`02`): `book` (title, dual-script fields, publisher, year…) +
  `copy` (accession no, almirah/shelf, status) + optional `loan`. One
  `search_text` column with Latin-folding + Devanagari transliteration makes
  "gaban", "gabaan" and "गबन" all match. Full 67-column migration mapping + cleaning rules.
- **UX** (`03`): Hindi-first bilingual labels, search-only home screen, 22px+ text,
  56px+ touch targets, giant yellow location panel, undo instead of confirm dialogs,
  voice search (hi-IN), banned-patterns list (no hamburgers/swipes/toasts).
